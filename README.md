# 🌐 Personal Portfolio Website

**HTML5 Beginner Project**

A clean and structured personal portfolio website built using pure HTML5 to demonstrate fundamental web development concepts, semantic structure, and basic form handling.

---

## 📖 About the Project

This project is a beginner-friendly personal portfolio website designed to showcase personal information, skills, and contact details in a well-organized layout. The goal was to understand how real websites are structured using semantic HTML and to practice building a multi-section static webpage from scratch.

The website includes internal navigation, structured content sections, a profile image, and a validated contact form.

---

## 🎯 Key Learning Outcomes

Through this project, I learned how to:

* Structure a complete webpage using HTML5
* Use semantic tags for better readability and accessibility
* Organize content into meaningful sections
* Implement internal navigation between sections
* Add images with proper accessibility attributes
* Create a functional contact form with validation
* Maintain clean and well-organized code

---

## 🛠️ Tech Stack

* **HTML5**
* No frameworks or external libraries used
* Built as a fully static website

## 🧱 Website Architecture

The webpage follows a semantic HTML layout:

* `<header>` → Displays name and navigation menu
* `<nav>` → Internal links to each section
* `<main>` → Main content container
* `<section>` → Individual content blocks
* `<footer>` → Copyright information

* Lists:

  * `textarea`
* Validation attributes:
